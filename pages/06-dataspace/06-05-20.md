## 문제 해결하기

Edge를 사용하다 문제가 생기면 아래 표에서 증상을 찾아 조치하세요.

| 단계 | 증상 | 조치 |
|---|---|---|
| 접속 | 로그인 화면이 반복해서 표시됨 | 포털에 먼저 로그인해 회사를 선택했는지, 앱 접근 권한이 있는지 확인하세요. |
| 오퍼링 | 오퍼링을 업로드하면 500 오류가 발생함 | '06-05-16 커넥터 관리하기'에서 커넥터의 API 주소, **API Header**, **API Value**가 맞는지 확인하세요. 값이 맞으면 커넥터 운영 담당자에게 정책 허브(정책 템플릿 서비스) 연결 확인을 요청하세요. |
| 카탈로그 | 조회 결과가 비어 있음 | 입력한 제공자 BPN이 맞는지, 제공자 접근 정책의 BPN이 소비자 회사의 BPN과 같은지 확인하세요. 그래도 비어 있으면 커넥터 운영 담당자에게 제공자 커넥터의 디지털 트윈 레지스트리(DTR) 자산 확인을 요청하세요. |
| 카탈로그 | 조회에 몇 분씩 걸림 | 소비자 커넥터에 데이터 접근 토큰이 쌓였을 수 있습니다. 커넥터 운영 담당자에게 토큰 확인과 정리를 요청하세요. |
| 구독 | REQUESTED에서 바뀌지 않거나 TERMINATED로 바뀜 | 제공자 정책의 조건이 소비자 회사와 맞는지 확인하세요. 정책에 문제가 없으면 커넥터 운영 담당자에게 회사 지갑(MIW)의 자격 증명 상태 확인을 요청하세요. |
| 다운로드 | 계약 관리에 FINALIZED 행이 여러 개 | 같은 제공자와 계약을 여러 건 맺은 경우입니다. Asset ID로 원하는 자산의 행을 찾아 다운로드하세요. |
| 다운로드 | 다운로드 이력에 실패 1 | 제공자 자산 정의의 OAuth2 Client ID와 Secret 별칭이 맞는지, 소스 주소에 접근할 수 있는지 확인하세요. |
| 다운로드 | 실패 상세에 'Token has expired'(토큰 만료) | 소비자 커넥터에 만료된 데이터 접근 토큰이 남아 있는 경우입니다. 커넥터 운영 담당자에게 만료된 토큰 정리를 요청한 뒤 다시 다운로드하세요. |
| 다운로드 | 데이터가 빈 값 | 자산의 소스 주소가 가리키는 데이터(FA³ST 값 또는 업로드한 행)에 값이 있는지 확인하세요. |
| 다운로드 | 자산 정의에서 엔드포인트를 수정해도 결과가 같음 | 자산 정의를 수정해도 이미 커넥터에 등록된 자산의 데이터 주소는 바뀌지 않습니다. '06-05-09 오퍼링 업로드하기'의 주의 내용에 따라 오퍼링을 다시 업로드하거나 커넥터 운영 담당자에게 변경을 요청하세요. |
