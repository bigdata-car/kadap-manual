## KADaP-X Edge와 연계하기

FA³ST의 값 조회 주소를 KADaP-X Edge 자산의 REST 소스로 등록해, 센서 값을 AAS를 거쳐 데이터스페이스로 교환합니다. 제공자 커넥터의 데이터플레인이 이 주소에 HTTP/1.1로 접속할 수 있어야 하므로, 보통 ① 방식으로 서버에서 실행한 FA³ST를 씁니다.

자산 정의에 입력하는 값과 소비자가 받는 데이터는 다음과 같습니다.

```text
# Edge > 공유 자산 > 자산 정의 > 소스 정보 (소스 유형 REST)
엔드포인트 : http://<FA³ST 주소>:8080/api/v3.0/submodels/<base64url>/$value   (GET)
인증       : OAuth2 — Token URL · Client ID · Client Secret 별칭 = 기존 기술 사용자 값 그대로

# 소비자가 다운로드하는 데이터
{"Temperature": 24.5, "Humidity": 51.2, "SensorId": "sensor01"}
```

### 구성

| 항목 | 설명 |
|---|---|
| 엔드포인트 | FA³ST의 값 조회 주소입니다. 제공자 커넥터의 데이터플레인이 소비자의 요청을 받으면 이 주소를 호출합니다. |
| 인증 | 자산 정의 양식에서 요구하는 OAuth2 값입니다. FA³ST는 이 토큰을 검사하지 않습니다. |
| 다운로드 데이터 | 소비자는 `$value` 응답 JSON을 그대로 받습니다. |

### Edge 자산으로 연계하기

FA³ST 값을 KADaP-X Edge 자산으로 연계하려면 다음 순서대로 진행하세요.

1. 브라우저에서 FA³ST(`http://<FA³ST 주소>:8080`)의 값 조회 주소를 열어 값이 표시되는지 확인하세요.
   - FA³ST 주소는 제공자 커넥터가 접속할 수 있는 주소여야 합니다.
2. Edge에서 **공유 자산** > **자산 정의** > **+ 생성**을 클릭하세요. ('06-05-05 자산 생성하기' 참고)
   - 자산 생성 화면이 표시됩니다.
3. 자산에 쓸 서브모델을 선택하고 소스 정보를 입력하세요.
   - **소스 유형**: **REST**를 선택합니다. 커넥터가 지정한 API 주소에서 데이터를 가져오는 방식입니다.
   - **엔드포인트**: FA³ST의 값 조회 주소를 입력하고, 호출 방식은 GET으로 지정합니다. (예: `http://<FA³ST 주소>:8080/api/v3.0/submodels/<base64url>/$value`)
   - **Token URL**, **Client ID**, **Client Secret**: 차례로 데이터스페이스 Keycloak의 토큰 주소, 회사 기술 사용자, Vault 시크릿 별칭을 입력합니다. 기존 기술 사용자 값을 그대로 씁니다.
4. **생성**을 클릭하세요.
5. **정책 정의**, **계약 정의**, **오퍼링 업로드**를 차례로 진행해 자산을 게시하세요.
6. 소비자 Edge의 **카탈로그**에서 자산을 찾아 구독하세요.
   - 계약이 자동으로 체결됩니다.
7. 소비자 Edge에서 자산을 **다운로드**해 `{"Temperature": …}` JSON을 받으세요.

> **주의 -** FA³ST에는 인증이 없어 접속할 수 있는 누구나 PUT, PATCH, POST, DELETE 요청으로 값을 바꾸거나 지울 수 있습니다. 외부에 공개할 때는 GET 요청만 통과시키는 프록시를 FA³ST 앞에 두고, 그 프록시 주소를 엔드포인트로 쓰세요. nginx에서는 `location / { limit_except GET { deny all; } proxy_pass http://<FA³ST 내부 주소>:8080; proxy_http_version 1.1; }`처럼 설정하면 GET과 HEAD 외의 요청을 거부합니다.
