## 서비스 구성

센서 값이 MQTT 브로커와 FA³ST Service를 거쳐 AAS 프로퍼티에 담기고, 표준 API와 KADaP-X Edge로 제공되는 흐름을 설명합니다.

### 화면 구성

AAS 연동 서비스는 다음과 같이 구성됩니다.

![a5-00-01.png](./../../assets/06-dataspace/a5-00-01.png)

| 번호 | 항목 | 설명 |
|---|---|---|
| 1 | 센서 | 센서 장치가 `sensors/<센서 ID>/temperature` 토픽에 `{"value": 24.5}` 형식으로 측정값을 발행합니다. |
| 2 | MQTT 브로커 | mosquitto 브로커입니다. ① 방식은 FA³ST와 함께 실행한 브로커 `<브로커 주소>:<포트>`를, ② 방식은 mqtt-client 모듈의 내장 브로커(1883)를 사용합니다. |
| 3 | 자산 연결 — MqttAssetConnection | FA³ST의 MQTT 자산 연결입니다. 구독 제공자(subscription provider)가 토픽에 들어온 값을 `(Submodel)<서브모델 ID>, (Property)Temperature` 참조가 가리키는 프로퍼티에 반영합니다. |
| 4 | AAS 모델 — model.json | 쉘 `Sensor_<센서 ID>`, 서브모델 `TempHumidity_<센서 ID>`, 프로퍼티 `Temperature`, `Humidity`, `SensorId`로 이어지는 구조에 값을 담습니다. |
| 5 | HTTP 엔드포인트 — AAS v3 API | AAS v3 API를 제공합니다. 쉘 목록은 `/api/v3.0/shells`, 서브모델 값은 `/api/v3.0/submodels/<base64url>/$value` 주소로 조회합니다. |
| 6 | 브라우저 · curl | 표준 API로 `{"Temperature": 24.5, …}` 같은 값을 조회합니다. |
| 7 | KADaP-X Edge | FA³ST의 값 조회 주소를 자산 정의의 REST 소스로 연결합니다. 제공자 커넥터가 이 주소에 접속할 수 있어야 합니다. |

### 구성 요소 살펴보기

설정 파일의 구독 항목 하나가 토픽 하나를 프로퍼티 하나에 연결합니다. 모델 파일, 설정 파일, FA³ST Service가 모두 AAS v3 규격을 따르므로 뷰어, 레지스트리, 커넥터 같은 다른 AAS 도구와 표준 주소로 연동할 수 있습니다. 구성 요소별 역할은 다음과 같습니다.

| 구성 요소 | 하는 일 | 예 |
|---|---|---|
| AAS 모델 파일 | 쉘, 서브모델, 프로퍼티의 구조와 초기값을 담습니다. JSON, XML, AASX 형식을 쓸 수 있습니다. | `model.json` |
| 설정 파일 | 엔드포인트, 값 저장 방식, 자산 연결을 지정합니다. 자산 연결에는 MQTT, OPC UA, HTTP를 쓸 수 있습니다. | `config.json` |
| FA³ST Service | 모델을 AAS v3 API로 제공하고, 자산 연결로 들어온 값을 프로퍼티에 반영합니다. | 이미지 `fraunhoferiosb/faaast-service:1.3` |
| MQTT 브로커 | 센서 값을 FA³ST에 전달합니다. | mosquitto |
| 조회 도구 | 브라우저나 curl로 API 응답 JSON을 확인합니다. FA³ST에는 별도의 관리 화면이 없습니다. | `http://<FA³ST 주소>:8080/api/v3.0/…` |
