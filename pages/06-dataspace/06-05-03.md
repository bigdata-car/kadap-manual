## 서브모델 등록하기

KADaP-X Edge의 **디지털 트윈** > **서브모델** 메뉴에서 서브모델을 등록할 수 있습니다.

### 화면 구성

서브모델 화면은 다음과 같이 구성됩니다.

![wiki-375325-2.png](./../../assets/06-dataspace/wiki-375325-2.png)

| 번호 | 항목 | 설명 |
|---|---|---|
| 1 | 서브모델 등록 | **+ 생성**을 클릭하면 서브모델 생성 화면으로 이동합니다. |
| 2 | 서브모델 목록 새로고침 | 더 보기(⋮) 아이콘을 클릭해 서브모델 목록을 새로고침할 수 있습니다. |
| 3 | 서브모델 목록 | 등록된 서브모델의 이름, 버전, 시맨틱 ID를 표시합니다. |
| 4 | 서브모델 상세 정보 보기 | 상세 보기 아이콘을 클릭하면 서브모델 상세 정보 창에서 버전, 시맨틱 ID 등을 확인할 수 있습니다. |

### 서브모델 등록하기

서브모델을 등록하려면 다음 순서대로 진행하세요.

1. KADaP-X Edge 홈 화면에서 **디지털 트윈** > **서브모델**을 클릭하세요.
   - 서브모델 화면이 표시됩니다.
2. **+ 생성**을 클릭하세요.
   - 서브모델 생성 화면이 표시됩니다.
3. **Upload file**을 클릭해 서브모델 스키마 파일(.json)을 업로드하세요.
   - 파일의 title, version, semantic_id 값이 이름, 버전, 시맨틱 ID 칸에 자동으로 입력됩니다.
4. 이름, 버전, 시맨틱 ID가 채워졌는지 확인하고 ID를 입력하세요.
   - **ID**: 영문 소문자, 숫자, 밑줄로 된 ID를 입력합니다. (예: `temphumidity_100`)
5. **업로드**를 클릭하세요.

> **참고 -** 서브모델은 .json 형식의 서브모델 스키마 파일로 등록합니다. 쉘이나 서브모델 인스턴스 같은 AAS 형식의 JSON 파일을 올리면 이름, 버전, 시맨틱 ID가 채워지지 않습니다.
