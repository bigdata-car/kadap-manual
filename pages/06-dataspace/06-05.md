# KADaP-X Edge

[TOC]

KADaP-X Edge는 커넥터(EDC)를 이용해 다른 회사와 계약을 맺고 데이터를 주고받는 앱입니다. 제공자는 자산, 정책, 계약을 정의해 오퍼링을 업로드하고, 소비자는 카탈로그에서 계약을 구독해 데이터를 다운로드합니다.

# 06-05-01 사용 순서

Edge 작업은 데이터를 제공하는 제공자 회사와 데이터를 받는 소비자 회사가 나눠서 진행합니다. 두 회사 모두 먼저 '06-05-02 홈 화면 구성'에서 메뉴를 살펴보고, '06-05-16 커넥터 관리하기'에서 provider와 consumer 커넥터가 등록되어 있는지 확인하세요.

### 제공자 작업 순서

데이터를 제공하려면 다음 순서대로 진행하세요.

1. 교환할 데이터의 형식을 정의한 서브모델을 등록하세요. ('06-05-03 서브모델 등록하기' 참고)
2. 서브모델과 데이터 소스를 지정해 자산을 정의하세요. ('06-05-04 자산 정의하기'와 '06-05-05 자산 생성하기' 참고)
3. 접근 정책에 소비자 회사의 BPN을 지정해 정책을 정의하세요. ('06-05-06 정책 정의하기'와 '06-05-07 정책 생성하기' 참고)
4. 자산과 정책을 묶어 계약을 정의하세요. ('06-05-08 계약 정의하기' 참고)
5. 계약을 오퍼링으로 업로드해 카탈로그에 게시하고, 디지털 트윈(쉘)이 등록되었는지 확인하세요. ('06-05-09 오퍼링 업로드하기'와 '06-05-10 디지털 트윈 레지스트리 확인하기' 참고)
6. 소비자가 구독한 계약과 전송 이력을 확인하세요. ('06-05-14 계약 관리하기(제공자)'와 '06-05-15 전송 이력 확인하기' 참고)

### 소비자 작업 순서

데이터를 받으려면 다음 순서대로 진행하세요.

1. 제공자 BPN으로 카탈로그를 조회하고 필요한 계약을 구독하세요. ('06-05-11 카탈로그 조회하고 구독하기' 참고)
2. 계약이 체결되었는지 확인하고 데이터를 다운로드하세요. ('06-05-12 계약 관리하고 다운로드하기(소비자)' 참고)
3. 다운로드 결과와 받은 데이터를 확인하세요. ('06-05-13 다운로드 이력 확인하기' 참고)

CSV 파일로 자산을 한꺼번에 업로드할 때는 '06-05-17 자산 업로드하기'를, 제품 탄소 발자국(PCF) 정보를 주고받을 때는 '06-05-18 PCF 요청하기'와 '06-05-19 PCF 응답 확인하기'를 참고하세요.

# 06-05-02 홈 화면 구성

KADaP-X Edge 홈 화면에서 각 메뉴로 이동하고 데이터 공유 절차 안내를 확인할 수 있습니다.

### 화면 구성

KADaP-X Edge 홈 화면은 다음과 같이 구성됩니다.

![wiki-375322-1.png](./../../assets/06-dataspace/wiki-375322-1.png)

| 번호 | 항목 | 설명 |
|---|---|---|
| 1 | 메뉴 | KADaP-X Edge의 메뉴를 선택할 수 있습니다. 메뉴별 기능은 표 아래에서 설명합니다. |
| 2 | 조직 정보 | 로그인한 사용자가 속한 회사나 조직 이름을 표시합니다. |
| 3 | 언어 설정 | 화면에 표시되는 언어를 한국어와 영어 중에서 선택할 수 있습니다. |
| 4 | 내 정보 | 로그인한 사용자 정보를 확인하고 로그아웃할 수 있습니다. |
| 5 | 데이터 공유 절차 안내 | 데이터 제공자와 소비자가 데이터를 공유하는 절차를 안내합니다. |

메뉴의 기능은 다음과 같습니다.

- **홈**: 홈 화면으로 이동합니다.
- **커넥터 관리**: 제공자용과 소비자용 커넥터를 등록하고 관리할 수 있습니다.
- **공유 자산**: 자산을 업로드하고, 데이터 교환에 쓸 자산, 정책, 계약을 정의해 관리할 수 있습니다.
- **디지털 트윈**: AAS 표준에 따른 디지털 트윈 레지스트리를 확인하고 서브모델을 등록할 수 있습니다.
- **PCF 관리**: 계약이 체결된 뒤 제공자에게 PCF(Product Carbon Footprint, 제품 탄소 발자국) 정보를 요청하고 응답을 확인할 수 있습니다.
- **커넥터 목록**: 커넥터별로 오퍼링 업로드, 카탈로그 조회, 계약 관리, 이력 확인 메뉴를 사용할 수 있습니다.

# 06-05-03 서브모델 등록하기

KADaP-X Edge의 **디지털 트윈** > **서브모델** 메뉴에서 서브모델을 등록할 수 있습니다.

### 화면 구성

서브모델 화면은 다음과 같이 구성됩니다.

![wiki-375325-2.png](./../../assets/06-dataspace/wiki-375325-2.png)

| 번호 | 항목 | 설명 |
|---|---|---|
| 1 | 서브모델 등록 | **+ 생성**을 클릭하면 서브모델 생성 화면으로 이동합니다. |
| 2 | 서브모델 목록 새로고침 | 더 보기(⋮) 아이콘을 클릭해 서브모델 목록을 새로고침할 수 있습니다. |
| 3 | 서브모델 목록 | 등록된 서브모델의 이름, 버전, 시맨틱 ID를 표시합니다. |
| 4 | 서브모델 상세 정보 보기 | 상세 보기 아이콘을 클릭하면 서브모델 상세 정보 창에서 버전, 시맨틱 ID 등을 확인할 수 있습니다. |

### 서브모델 등록하기

서브모델을 등록하려면 다음 순서대로 진행하세요.

1. KADaP-X Edge 홈 화면에서 **디지털 트윈** > **서브모델**을 클릭하세요.
   - 서브모델 화면이 표시됩니다.
2. **+ 생성**을 클릭하세요.
   - 서브모델 생성 화면이 표시됩니다.
3. **Upload file**을 클릭해 서브모델 스키마 파일(.json)을 업로드하세요.
   - 파일의 title, version, semantic_id 값이 이름, 버전, 시맨틱 ID 칸에 자동으로 입력됩니다.
4. 이름, 버전, 시맨틱 ID가 채워졌는지 확인하고 ID를 입력하세요.
   - **ID**: 영문 소문자, 숫자, 밑줄로 된 ID를 입력합니다. (예: `temphumidity_100`)
5. **업로드**를 클릭하세요.

> **참고 -** 서브모델은 .json 형식의 서브모델 스키마 파일로 등록합니다. 쉘이나 서브모델 인스턴스 같은 AAS 형식의 JSON 파일을 올리면 이름, 버전, 시맨틱 ID가 채워지지 않습니다.

자산 정의 화면은 다음과 같이 구성됩니다.

| 번호 | 항목 | 설명 |

| 1 | 자산 정보 등록 | **+ 생성**을 클릭하면 자산 생성 화면으로 이동합니다. 자세한 내용은 '06-05-05 자산 생성하기'를 참고하세요. |
| 2 | 자산 목록 새로고침 | 더 보기(⋮) 아이콘을 클릭해 자산 목록을 새로고침할 수 있습니다. |
| 3 | 자산 상세 정보 보기 | 상세 보기 아이콘을 클릭하면 등록한 자산 정보를 확인할 수 있습니다. |
| 4 | 자산 정의 관리 | 행의 더 보기(⋮) 아이콘을 클릭하면 **수정**과 **삭제** 메뉴가 표시됩니다. **수정**을 클릭하면 자산 편집 화면으로 이동하고, **삭제**한 자산은 복구할 수 없습니다. |

# 06-05-05 자산 생성하기

자산 생성 화면에서 자산 이름, 서브모델, 데이터 소스를 지정해 자산을 등록할 수 있습니다.

### 화면 구성

자산 생성 화면 아래쪽의 소스 정보 영역은 다음과 같이 구성됩니다. 위쪽의 자산, 서브모델, 소스 유형은 아래 절차에서 설명합니다.

![wiki-375324-3.png](./../../assets/06-dataspace/wiki-375324-3.png)

| 번호 | 항목 | 설명 |
|---|---|---|
| 1 | 소스 정보 | 자산 데이터를 가져올 곳의 엔드포인트와 인증 정보를 입력하는 영역입니다. |
| 2 | 엔드포인트 | **Method**에서 API 호출 방식을 선택하고, **Base URL**에 데이터를 가져올 API 주소를 입력합니다. |
| 3 | 인증 | **인증 유형**(예: **Oauth2**)을 선택하고 **Token URL**, **Client ID**, **Client Secret**을 입력합니다. |

### 자산 생성하기

자산을 생성하려면 다음 순서대로 진행하세요.

1. KADaP-X Edge 홈 화면에서 **공유 자산** > **자산 정의**를 클릭하세요.
   - 자산 정의 화면이 표시됩니다.
2. **+ 생성**을 클릭하세요.
   - 자산 생성 화면이 표시됩니다.
3. 자산 생성 화면 위쪽의 항목을 입력하세요.
   - **자산**: 자산 이름과 설명을 입력합니다.
   - **서브모델**: **+ 생성**을 클릭해 자산에 적용할 서브모델을 선택합니다. 자산을 업로드했다면 업로드할 때와 같은 서브모델이어야 합니다. 선택한 서브모델은 상세 보기 아이콘으로 확인하고, 변경 아이콘으로 바꿀 수 있습니다.
   - **소스 유형**: **REST**와 **CSV** 중에서 선택합니다. **REST**는 외부 API에서 데이터를 가져오는 방식으로, 연결 정보와 인증 정보를 그림의 소스 정보에 입력합니다. **CSV**는 업로드한 CSV 파일을 데이터 소스로 사용합니다.
4. 그림의 소스 정보에 엔드포인트와 인증 정보를 입력하세요.
5. **생성**을 클릭하세요.

# 06-05-07 정책 생성하기

정책 생성 화면에서 계약에 적용할 접근 정책과 사용 정책을 등록할 수 있습니다.

### 화면 구성

정책 생성 화면은 다음과 같이 구성됩니다.

![fs-edge-2-policy-create.png](./../../assets/06-dataspace/fs-edge-2-policy-create.png)

| 번호 | 항목 | 설명 |
|---|---|---|
| 1 | 정책 정보 | 정책명과 설명을 입력합니다. |
| 2 | 접근 정책 | **+ 정책 추가**로 유형과 값을 추가하고, 추가한 항목은 **삭제**로 지울 수 있습니다. 이 조건에 맞는 회사만 카탈로그에서 계약을 조회할 수 있습니다. |
| 3 | 사용 정책 | **+ 정책 추가**를 클릭해 계약 체결 뒤 데이터를 사용할 수 있는 범위를 유형과 값으로 추가합니다. |

### 정책 생성하기

정책을 생성하려면 다음 순서대로 진행하세요.

1. KADaP-X Edge 홈 화면에서 **공유 자산** > **정책 정의**를 클릭하세요.
   - 정책 정의 화면이 표시됩니다.
2. **+ 생성**을 클릭하세요.
   - 정책 생성 화면이 표시됩니다.
3. 정책명과 설명을 입력하세요.
4. 접근 정책의 **+ 정책 추가**를 클릭하고, 데이터를 받을 회사를 다음과 같이 지정하세요.
   - **유형**: BPN을 선택합니다.
   - **값**: 소비자 회사의 BPN을 입력합니다.
5. 필요하면 사용 정책의 **+ 정책 추가**를 클릭해 유형과 값을 추가하세요.
6. **생성**을 클릭하세요.

> **참고 -** 접근 정책의 BPN 값은 소비자 회사의 BPN과 정확히 같아야 합니다. 값이 다르면 소비자가 카탈로그를 조회해도 결과가 표시되지 않습니다. 소비자 회사의 BPN은 포털의 '06-01-10 파트너 네트워크'에서 확인할 수 있습니다.

3. 계약 생성 화면의 항목을 입력하세요.
   - **계약 정보**: 계약 이름과 설명을 입력합니다.
   - **자산 설정**: **+ 생성**을 클릭하고, 자산 목록에서 계약에 포함할 자산을 선택한 뒤 **+ 선택**을 클릭합니다. 추가한 자산은 상세 정보와 함께 표시되며, 이름 오른쪽의 삭제(×) 아이콘으로 지우고 다시 선택할 수 있습니다.
   - **정책 설정**: **+ 생성**을 클릭하고, 정책 목록에서 계약에 적용할 정책을 선택한 뒤 **+ 선택**을 클릭합니다. 추가한 정책은 상세 정보와 함께 표시되며, 이름 오른쪽의 삭제(×) 아이콘으로 지우고 다시 선택할 수 있습니다.
4. **생성**을 클릭하세요.

# 06-05-09 오퍼링 업로드하기

오퍼링 업로드 화면에서는 미리 정의한 계약을 provider 커넥터에 업로드해 카탈로그에 게시할 수 있습니다.

### 화면 구성

오퍼링 업로드 화면은 다음과 같이 구성됩니다.

![fs-edge-2-provider-offering.png](./../../assets/06-dataspace/fs-edge-2-provider-offering.png)

| 번호 | 항목 | 설명 |
|---|---|---|
| 1 | 커넥터 목록 > provider | **오퍼링 업로드**, **계약 관리**, **전송 이력** 메뉴를 선택할 수 있습니다. |
| 2 | 계약 선택 · 생성 | **+ 생성**을 클릭하면 계약 선택 창이 표시됩니다. 계약을 선택하면 그 계약의 자산과 정책 정보가 이 영역에 나타납니다. |
| 3 | 이전 · 업로드 | **업로드**를 클릭하면 선택한 계약이 provider 커넥터에 업로드되어 카탈로그에 게시됩니다. **이전**을 클릭하면 계약 정의 화면으로 돌아갑니다. |

### 오퍼링 업로드하기

오퍼링을 업로드하려면 다음 순서대로 진행하세요.

1. KADaP-X Edge 홈 화면에서 **커넥터 목록** > **provider [제공자]** > **오퍼링 업로드**를 클릭하세요.
   - 오퍼링 업로드 화면이 표시됩니다.
2. **+ 생성**을 클릭하세요.
   - 계약 선택 창이 표시됩니다.
3. 업로드할 계약을 선택하고 **선택**을 클릭하세요.
   - 선택한 계약의 자산과 정책 정보가 표시됩니다.
4. 자산과 정책 정보를 확인하고 **업로드**를 클릭하세요.
   - 자산이 커넥터에 등록되어 카탈로그에 게시되고, 디지털 트윈(쉘)도 자동으로 등록됩니다.

> **주의 -** 오퍼링을 업로드한 뒤에는 자산 정의 화면에서 엔드포인트를 **수정**해도 이미 커넥터에 등록된 자산의 데이터 주소가 바뀌지 않습니다. 주소를 바꾸려면 새 자산을 정의하고, 그 자산으로 계약을 만들어 오퍼링을 다시 업로드하세요. 또는 커넥터 운영 담당자에게 데이터 주소 변경과 소비자 커넥터의 데이터 접근 토큰 정리를 요청하세요.

# 06-05-11 카탈로그 조회하고 구독하기

카탈로그 조회 화면에서 제공자 BPN으로 제공자가 게시한 계약을 찾아 구독할 수 있습니다.

카탈로그 조회 화면은 다음과 같이 구성됩니다.

![fs-edge-catalog-search.png](./../../assets/06-dataspace/fs-edge-catalog-search.png)

| 2 | BPN 검색 · 검색 | 제공자 BPN을 입력하고 **검색**을 클릭합니다. |
| 3 | 결과 목록 | 제공자가 게시한 계약의 이름, 제공자, 유형, 설명을 표시합니다. 이름은 모두 ShellTwinIdShortNotVisible로 표시되므로 유형과 설명으로 계약을 구분합니다. |
| 4 | 행 체크박스 | 구독할 계약을 선택합니다. 선택한 뒤 **구독**을 클릭하면 구독 상세정보 창이 표시됩니다. |

   - 카탈로그 조회 화면이 표시됩니다.
2. 제공자 **BPN**을 입력하고 **검색**을 클릭하세요.

   - 구독 상세정보 창이 표시됩니다.
4. 구독 상세정보 창에서 **구독**을 클릭하세요.
5. **계약 관리**에서 구독한 자산의 Asset ID로 계약 행을 찾아 Status가 REQUESTED에서 **FINALIZED**로 바뀌었는지 확인하세요. 아직 바뀌지 않았으면 10~20초 뒤 목록을 새로고침하세요.
   - 제공자 커넥터가 정책을 확인해 계약을 자동으로 체결하므로, 제공자가 따로 처리할 일은 없습니다.

> **참고 -** 제공자 BPN은 포털의 '06-01-10 파트너 네트워크'에서 확인할 수 있습니다.

# 06-05-12 계약 관리하고 다운로드하기(소비자)

계약 관리 화면에서 제공자와 맺은 계약의 상태를 확인하고, 데이터를 다운로드하거나 구독을 취소할 수 있습니다.

### 화면 구성

계약 관리 화면은 다음과 같이 구성됩니다.

![wiki-375328-1.png](./../../assets/06-dataspace/wiki-375328-1.png)

| 번호 | 항목 | 설명 |
|---|---|---|
| 1 | 계약 목록 새로고침 | 더 보기(⋮) 아이콘을 클릭해 계약 목록을 새로고침할 수 있습니다. |
| 2 | Negotiation ID | 계약을 식별하는 고유 번호로, 시스템이 자동으로 부여합니다. |

| 5 | Status | 계약 상태를 표시합니다. **FINALIZED**는 계약이 체결된 상태로, 이 상태에서만 데이터를 교환할 수 있습니다. |

체결된 계약의 데이터를 다운로드하려면 다음 순서대로 진행하세요.

1. KADaP-X Edge 홈 화면에서 **커넥터 목록** > **consumer [소비자]** > **계약 관리**를 클릭하세요.
   - 계약 관리 화면이 표시됩니다.
2. 구독한 계약의 Status가 **FINALIZED**인지 확인하세요. 아직 REQUESTED이면 10~20초 뒤 목록을 새로고침하세요.
3. Status가 **FINALIZED**인 행의 더 보기(⋮) > **다운로드**를 클릭하세요.

결과를 보려면 '06-05-13 다운로드 이력 확인하기'를 참고하세요.

> **참고 -** 계약 관리에 FINALIZED 행이 여러 개이면 **Asset ID**로 원하는 자산의 행을 찾으세요.

> **주의 -** 더 보기(⋮) 메뉴의 **구독취소**를 클릭하면 계약이 취소되어, 같은 소비자 커넥터를 쓰는 모든 사용자가 그 자산을 다운로드할 수 없게 됩니다.

|---|---|---|

| 2 | 전송 이력 목록 새로고침 | 더 보기(⋮) 아이콘을 클릭해 전송 이력 목록을 새로고침할 수 있습니다. |
| 3 | ID | 데이터 전송을 식별하는 ID로, 상세 내역을 조회할 때 사용합니다. |
| 4 | 상태 | 데이터 전송의 처리 결과(예: **COMPLETED**)를 표시합니다. |
| 5 | 성공 · 실패 · 갱신 · 삭제 · 총 | 성공과 실패는 전송에 성공하거나 실패한 건수이고, 갱신과 삭제는 변경되거나 삭제된 데이터 건수입니다. 총은 전체 처리 건수입니다. |
| 6 | 시작일 · 종료일 | 데이터 전송이 시작된 일시와 완료된 일시를 표시합니다. 전송은 소비자가 다운로드를 요청하면 시작됩니다. |
| 7 | 전송 상세 정보 보기 | 상세 보기 아이콘을 클릭하면 전송된 데이터의 상세 정보를 확인할 수 있습니다. |

### 전송 결과 확인하기

전송 결과를 확인하려면 다음 순서대로 진행하세요.

1. KADaP-X Edge 홈 화면에서 **커넥터 목록** > **provider [제공자]** > **전송 이력**을 클릭하세요.
   - 전송 이력 화면이 표시됩니다.
2. 각 전송의 상태와 성공, 실패 건수를 확인하세요.

# 06-05-16 커넥터 관리하기

KADaP-X Edge의 **커넥터 관리** 메뉴에서 커넥터를 등록하고 관리할 수 있습니다.

### 화면 구성

커넥터 관리 화면은 다음과 같이 구성됩니다.

![wiki-375323-1.png](./../../assets/06-dataspace/wiki-375323-1.png)

| 번호 | 항목 | 설명 |
|---|---|---|
| 1 | 커넥터 등록 | **+ 생성**을 클릭하면 커넥터 생성 화면으로 이동합니다. |
| 2 | 커넥터 정렬 필터 | **Sort by**에서 커넥터 카드의 정렬 순서를 선택합니다. |
| 3 | 커넥터 관리 메뉴 | 카드의 더 보기(⋮) 아이콘을 클릭하면 **수정**과 **삭제** 메뉴가 표시됩니다. **수정**을 클릭하면 커넥터 수정 화면으로 이동하고, **삭제**한 커넥터는 복구할 수 없습니다. |
| 4 | 커넥터 정보 카드 | 등록한 커넥터의 이름, 설명, 커넥터 주소, API 주소, 유형(PROVIDER 또는 CONSUMER), 등록 일시를 표시합니다. |

### 커넥터 확인하고 등록하기

커넥터를 확인하고 새로 등록하려면 다음 순서대로 진행하세요.

1. KADaP-X Edge 홈 화면에서 **커넥터 관리**를 클릭하세요.
   - 커넥터 관리 화면이 표시됩니다.
2. **provider**와 **consumer** 커넥터 카드가 모두 있는지 확인하세요. 데이터를 공유하려면 두 커넥터가 모두 등록되어 있어야 합니다.
3. 등록되지 않은 커넥터가 있으면 **+ 생성**을 클릭하세요.
   - 커넥터 생성 화면이 표시됩니다.
4. 커넥터 생성 화면의 항목을 입력하세요.
   - **커넥터명**: 커넥터 이름을 입력합니다. 제공자 커넥터는 provider, 소비자 커넥터는 consumer처럼 유형과 같게 정하면 구분하기 쉽습니다.
   - **설명**: 커넥터 설명을 입력합니다.
   - **Dataspace**: 데이터스페이스를 선택합니다. **KADaP-X**를 선택하면 KADaP-X 데이터스페이스의 다른 커넥터와 데이터를 교환할 수 있습니다.
   - **커넥터 유형**: 데이터 제공자는 **Provider**, 소비자는 **Consumer**를 선택합니다.
   - **서비스 형식**: 커넥터 운영 방식을 선택합니다. **Self Hosted**는 회사가 커넥터를 직접 설치해 운영하는 방식으로, 보안이 중요할 때 선택합니다. **CaaS**(Connector as a Service)는 KADaP이 클라우드에서 커넥터를 대신 운영하는 방식으로, 따로 서버를 구축하지 않아도 됩니다.
   - **Base URL**: 커넥터의 프로토콜 주소를 입력합니다. 다른 회사의 커넥터가 카탈로그 조회, 계약 협상, 전송 요청에 사용하는 주소입니다.
   - **데이터플레인 URL**: 계약이 체결된 뒤 실제 데이터를 주고받는 데 쓰는 커넥터 주소를 입력합니다.
   - **API Header**와 **API Value**: 커넥터 관리 API를 호출할 때 쓰는 인증 헤더의 이름과 값(토큰)을 입력합니다. 두 값은 커넥터 운영 담당자에게 받아 입력합니다.
5. **생성**을 클릭하세요.

> **주의 -** 운영 중인 커넥터를 **수정**하거나 **삭제**하면 그 커넥터를 쓰는 데이터 교환이 모두 멈출 수 있습니다. 커넥터 정보는 커넥터 운영 담당자와 협의한 뒤에 변경하세요.

# 06-05-17 자산 업로드하기

KADaP-X Edge의 **공유 자산** > **자산 업로드** 메뉴에서 서브모델 템플릿에 맞춘 자산 데이터를 업로드할 수 있습니다.

# 06-05-20 문제 해결하기

Edge를 사용하다 문제가 생기면 아래 표에서 증상을 찾아 조치하세요.

| 단계 | 증상 | 조치 |
|---|---|---|
| 접속 | 로그인 화면이 반복해서 표시됨 | 포털에 먼저 로그인해 회사를 선택했는지, 앱 접근 권한이 있는지 확인하세요. |
| 오퍼링 | 오퍼링을 업로드하면 500 오류가 발생함 | '06-05-16 커넥터 관리하기'에서 커넥터의 API 주소, **API Header**, **API Value**가 맞는지 확인하세요. 값이 맞으면 커넥터 운영 담당자에게 정책 허브(정책 템플릿 서비스) 연결 확인을 요청하세요. |
| 카탈로그 | 조회 결과가 비어 있음 | 입력한 제공자 BPN이 맞는지, 제공자 접근 정책의 BPN이 소비자 회사의 BPN과 같은지 확인하세요. 그래도 비어 있으면 커넥터 운영 담당자에게 제공자 커넥터의 디지털 트윈 레지스트리(DTR) 자산 확인을 요청하세요. |
| 카탈로그 | 조회에 몇 분씩 걸림 | 소비자 커넥터에 데이터 접근 토큰이 쌓였을 수 있습니다. 커넥터 운영 담당자에게 토큰 확인과 정리를 요청하세요. |
| 구독 | REQUESTED에서 바뀌지 않거나 TERMINATED로 바뀜 | 제공자 정책의 조건이 소비자 회사와 맞는지 확인하세요. 정책에 문제가 없으면 커넥터 운영 담당자에게 회사 지갑(MIW)의 자격 증명 상태 확인을 요청하세요. |
| 다운로드 | 계약 관리에 FINALIZED 행이 여러 개 | 같은 제공자와 계약을 여러 건 맺은 경우입니다. Asset ID로 원하는 자산의 행을 찾아 다운로드하세요. |
| 다운로드 | 다운로드 이력에 실패 1 | 제공자 자산 정의의 OAuth2 Client ID와 Secret 별칭이 맞는지, 소스 주소에 접근할 수 있는지 확인하세요. |
| 다운로드 | 실패 상세에 'Token has expired'(토큰 만료) | 소비자 커넥터에 만료된 데이터 접근 토큰이 남아 있는 경우입니다. 커넥터 운영 담당자에게 만료된 토큰 정리를 요청한 뒤 다시 다운로드하세요. |
| 다운로드 | 데이터가 빈 값 | 자산의 소스 주소가 가리키는 데이터(FA³ST 값 또는 업로드한 행)에 값이 있는지 확인하세요. |
| 다운로드 | 자산 정의에서 엔드포인트를 수정해도 결과가 같음 | 자산 정의를 수정해도 이미 커넥터에 등록된 자산의 데이터 주소는 바뀌지 않습니다. '06-05-09 오퍼링 업로드하기'의 주의 내용에 따라 오퍼링을 다시 업로드하거나 커넥터 운영 담당자에게 변경을 요청하세요. |
