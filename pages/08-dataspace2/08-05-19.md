## PCF 응답 확인하기

KADaP-X Edge의 **PCF 관리** > **PCF 응답** 메뉴에서 받은 PCF 요청의 처리 상태를 확인하고, 요청에 응답해 PCF 데이터를 전송할 수 있습니다.

### 화면 구성

PCF 응답 화면은 다음과 같이 구성됩니다.

![wiki-375326-2.png](./../../assets/08-dataspace/wiki-375326-2.png)

| 번호 | 항목 | 설명 |
|---|---|---|
| 1 | PCF 응답 목록 새로고침 | 더 보기(⋮) 아이콘을 클릭해 PCF 응답 목록을 새로고침할 수 있습니다. |
| 2 | 상태 | 요청 처리 상태를 표시합니다. REQUESTED는 요청 접수, PUSHED는 데이터 전송 완료, FAILED_TO_PUSH_DATA는 전송 실패를 뜻합니다. |

### PCF 응답 확인하고 전송하기

PCF 응답을 확인하고 데이터를 전송하려면 다음 순서대로 진행하세요.

1. KADaP-X Edge 홈 화면에서 **PCF 관리** > **PCF 응답**을 클릭하세요.
   - PCF 응답 화면이 표시됩니다.
2. 응답 목록에서 각 요청의 상태를 확인하세요.
3. 그 행 끝의 **PCF 데이터 전송** 아이콘을 클릭해 요청에 응답하세요.
4. 시맨틱 ID와 데이터를 보낼 provider 커넥터를 선택하고 **전송**을 클릭하세요.
   - 전송이 끝나면 상태가 **PUSHED**로 바뀝니다.
