## 설정 파일 이해하기

설정 파일 `config.json`으로 FA³ST Service의 엔드포인트, 값 저장 방식, 자산 연결을 지정합니다. 설정 파일은 `core`, `endpoints`, `persistence`, `fileStorage`, `messageBus`, `assetConnections`의 여섯 항목으로 이루어지며, 아래 예에서는 `fileStorage`를 생략했습니다. 구현을 고르는 항목에는 구현 클래스 이름 `@class`와 그 구현의 속성을 씁니다.

```json
{ "core": { "requestHandlerThreadPoolSize": 4 },
  "endpoints": [ { "@class": "de.fraunhofer.iosb.ilt.faaast.service.endpoint.http.HttpEndpoint",
      "port": 8080, "sslEnabled": false, "httpVersion": "HTTP_1_1", "corsEnabled": true, "includeErrorDetails": true } ],
  "persistence": { "@class": "de.fraunhofer.iosb.ilt.faaast.service.persistence.memory.PersistenceInMemory",
      "initialModelFile": "/app/resources/model.json" },
  "messageBus": { "@class": "de.fraunhofer.iosb.ilt.faaast.service.messagebus.internal.MessageBusInternal" },
  "assetConnections": [ { "@class": "de.fraunhofer.iosb.ilt.faaast.service.assetconnection.mqtt.MqttAssetConnection",
      "serverUri": "tcp://mqtt:1883", "clientId": "faaast-edu",
      "subscriptionProviders": { "…": "'MQTT 자산 연결하기' 참고" } } ] }
```

### 구성

| 항목 | 설명 |
|---|---|
| `core` | API 요청을 동시에 처리할 스레드 수 `requestHandlerThreadPoolSize`를 지정합니다. |
| `endpoints[0]` | HTTP 엔드포인트입니다. `port`, `sslEnabled`, `httpVersion`, `corsEnabled`, `includeErrorDetails`를 지정합니다. |
| `persistence` | 값 저장 방식입니다. 이 예는 메모리 저장을 쓰고, 처음 읽을 모델 파일을 `initialModelFile`로 지정합니다. |
| `messageBus` | FA³ST 내부에서 이벤트를 전달하는 메시지 버스입니다. |
| `assetConnections[0]` | MQTT 자산 연결입니다. `serverUri`, `clientId`, `subscriptionProviders`를 지정합니다. |

### 설정 파일 작성하기

설정 파일을 작성하려면 다음 순서대로 진행하세요.

1. `@class`에 쓸 클래스 이름은 공식 문서에서 복사하세요. 클래스 이름은 모두 `de.fraunhofer.iosb.ilt.faaast.service`로 시작합니다.
2. SSL을 껐다면 `httpVersion`을 반드시 `HTTP_1_1`로 지정하세요. 기본값 HTTP_2로 두면 브라우저와 curl이 빈 응답을 받습니다.
3. 설정 파일을 고치지 않고 값만 바꾸려면 명령줄이나 환경변수로 덮어쓰세요. 형식은 아래 표를 참고하세요.
4. 기동 로그 첫 줄의 **Config: /app/resources/config.json (ENV)**와 **Model: … (ENV)**를 보고, 마운트한 파일 경로와 환경변수가 맞는지 확인하세요.

엔드포인트 기본값과 덮어쓰기 방법은 다음과 같습니다.

| 항목 | 설명 | 예 |
|---|---|---|
| 엔드포인트 기본값 | 포트 443, HTTPS(자체 서명 인증서), HTTP_2, CORS 끔이 기본값입니다. | 이 절의 설정은 8080, `false`, `HTTP_1_1`, `true` |
| 명령줄 덮어쓰기 | `<JSONPath>=<값>` 형식으로 씁니다. JSONPath 앞의 `$.`은 생략합니다. | `endpoints[0].port=8081` |
| 환경변수 덮어쓰기 | `faaast_config_extension_` 뒤에 경로를 붙입니다. 경로의 `.`은 `_`로 바꿉니다. | `faaast_config_extension_endpoints[0]_port=8081` |
